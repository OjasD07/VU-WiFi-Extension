01What this extension does

VU Wi-Fi Auto Login is an independent Chrome extension that automates the captive portal flow on the configured VU Wi-Fi gateway at 10.25.0.1. When the extension is enabled and consent has been accepted, it can:

  • Fill the campus login form with the username and password you saved.
  • Submit the form and dismiss authentication keepalive pages without clicking logout.
  • Check the network policy checkbox and accept the network terms when that option is enabled.
  • Watch for asynchronously rendered portal controls and act on them when they appear.

The extension is a convenience tool. It is not affiliated with, endorsed by, or operated by VU or the network administrator. Your network access remains subject to the rules and policies of the network you join.

04How page access works

A content script runs on http:// pages and on the configured portal host so it can recognize captive-portal screens after a redirect. The script reads visible page text, titles, URLs, and form controls locally in your browser. It only fills or clicks controls when the page strongly matches a captive portal, login, keepalive, or network-terms screen.

The page content is processed in memory to make that decision. It is not logged, stored, or transmitted by the extension. Broad page access is limited to http:// URLs; HTTPS access is limited to the configured 10.25.0.1 gateway.

05Network activity

The extension itself makes no network requests. When it fills and submits a portal form, your browser sends the credentials to the portal page you are already visiting, exactly as a manual login would. The keepalive continuation link is opened in a new tab so the keepalive page can remain active in the background.

07Your controls

  • Withdraw consent on this page at any time. Automation pauses immediately.
  • Disable automation from the extension popup without withdrawing consent.
  • Delete stored data by clearing the extension's storage or removing the extension in chrome://extensions.
  • Change credentials at any time from the popup. Saved values are replaced locally.

08Security and shared devices

Anyone with access to your Chrome profile and the extension's storage may be able to read the saved credentials. Use a trusted device and a locked operating-system account. If you use a shared computer, remove the extension and clear its data before signing out.
